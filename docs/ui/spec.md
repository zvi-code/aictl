## How to read the rows

- **L — Loading:** the first usable answer for this key is pending. **E — Empty:** a successful answer reports no matching or applicable data. **X — Error:** the read or action failed. **S — Stale/partial:** keep applicable last values, identify stale, incomplete, unreported, or unavailable data; do not treat them as zero, a successful empty answer, or current data. **R — Ready:** usable values for the active key. Keep all states in the same content box (P3); do not substitute another source or scope for missing data (S3/S5).
- `B` in the states column supplies L/X/S for Overview: show board loading (including local startup on 503), show source or board errors, retain only applicable last values and label disconnect/stale or separate source failure. Many old panels render empty defaults during load or lack their own error display; see `DEF-01`. `C` supplies L/X/S for Context: wait for inventory; show when the source is unavailable; distinguish recorded metadata/estimates from local file content. `H` supplies L/X/S for Health: wait for live health, show no-history-substitute error, or retain the last response and report stale/pending or missing contributors. `D` supplies L/X/S for drawer detail: wait for chunk/read; show request error with no result; retain only data for the same key and identify missing detail/retention. The old detail refresh gap is `DEF-02`. `T` supplies L/X/S for Settings: wait for chunk and configuration, show failure separately, keep last values on refresh failure or report unsupported remote data. Row-specific text adds to or overrides these definitions.
- `K` means native Tab/Shift+Tab order and native button, link, form, or disclosure activation. `Grid` adds sortable header buttons, primary-cell row action and fold buttons, and, where enabled, keyboard column width (Left/Right; double-click resets). `Chart` adds legend toggle, pointer hover/brush, Left/Right for buckets, Enter to apply the selected bucket, and Escape to clear/dismiss; only board-range charts drive the board selection. Sources: `C:\OSS\aictl\src\aictl\dashboard\ui\src\components\board\Table.js:17–69`, `C:\OSS\aictl\src\aictl\dashboard\ui\src\components\board\colWidths.js:64–80`, `C:\OSS\aictl\src\aictl\dashboard\ui\src\components\board\Chart.js:63–143`, `C:\OSS\aictl\src\aictl\dashboard\ui\src\components\board\Panel.js:89–103`.
- `Board` in the URL column inherits `SHL-04`; `Drawer` inherits `DRW-01`; `Settings` inherits `SET-01`. “Local state” means browser component state, not a query or hash parameter. Do not copy private text into a dashboard URL.

## Phase 3 visual follow-up

The 14 Overview panels now lead with counts and compact bar charts or uPlot histograms. They use the existing reads and keep their detail tables, stable row keys, filters and actions. Overview and Health share the token-based `Meter` primitive. Health uses Stat tiles and uPlot comparisons before expandable diagnostics.

The default 1440 × 900 Overview shows both the Tokens and Cache hit rate canvases without scrolling. Panels with live detail reserve the stale notice's space when values become current so the content stays in place.

The BRD-01 KPI detail grid anchors the sparkline in a reserved trailing slot. A missing series leaves the slot blank, not zero. Changes to comparison text do not move the sparkline horizontally.

BRD-02–04: `agentActivity` opens the default Agents section. It reads the **selected** board result, not the whole-range brush series. `scope.shown_agents` and `scope.shown_sessions` describe recorded history for `range.since`–`range.until`; they are not counts of live processes or visible table rows. The message chart and its keyboard-accessible data table use `series.messages` and `range.bucket_starts` and mark `range.partial_bucket`. The four largest reported `by_model[].tokens` totals share a scale relative to the largest. Focus a model for its exact count; selecting it toggles the model filter without discarding the other filters, and browser Back restores the previous selection. Failed tool calls and their rate come from `kpis`, not the attention list. The original attention, agent, model and role tables retain their drill-downs. Saved layouts are not overwritten; **Add panel** or **Reset layout** makes the new panel available there.
